# 📝 Note Taking Application

A modern full-stack Note Taking Web Application built using Spring Boot, Thymeleaf, MySQL, and Bootstrap.

---

# 🚀 Features

✅ User Signup & Login  
✅ Session Management  
✅ User-Specific Notes  
✅ Create Notes  
✅ Edit Notes  
✅ Delete Notes  
✅ Search Notes  
✅ Responsive Dashboard  
✅ Password Show/Hide Feature  
✅ Duplicate Email Validation  
✅ Beautiful Bootstrap UI  

---
